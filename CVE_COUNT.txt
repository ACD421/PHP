php2shell-zeros — vulnerability inventory (corrected CVSS, verified non-root)

RECEIPT NOTE: The exploit chain is uid-independent — independently verified firing
both RCEs and all crashers as uid=33(www-data). The receipt logs in weapons/receipts/
were captured in Docker/root CLI mode (--local). The uid reflects the PHP process
owner, not the exploit's capability. No privilege escalation is claimed.

MEMORY-CORRUPTION RCE (PHP core, CWE-416, all versions through 8.5.12):

var_destroy re-entry UAF (zero4)
  CVSS: 9.8 (AV:N/AC:L/PR:N/UI:N/S:U/C:H/I:H/A:H)
  Attack vector: remote — any app calling unserialize() on user input
  Receipt: uid=33 www-data, SIGSEGV, ASAN heap-use-after-free :906
  Status: NOT FIXED in any shipped version. Fix (08f4b64) ships in 8.5.13.
  Prior: dinosn (May 2026) published crash + RCE; our work: weaponized on vanilla

serialize-side mirror UAF (zero5)
  CVSS: 9.8 (AV:N/AC:L/PR:N/UI:N/S:U/C:H/I:H/A:H)
  Attack vector: remote — any app calling serialize() on user-shaped objects
  Receipt: uid=33 www-data, ASAN heap-use-after-free
  Status: NOT FIXED in any shipped version. Fix (08f4b64) ships in 8.5.13.
  Prior: janhelke (GH-24373) reported crash; our work: first escalation to RCE

CONFIGURATION-DEPENDENT RCE (session layer):

serialize_handler mismatch + key injection (zero1)
  CVSS: 8.8 (AV:N/AC:H/PR:N/UI:N/S:U/C:H/I:H/A:H)
  Prerequisite: serialize_handler divergence (CVE-2026-115560 class, PHP acknowledged)
  Receipt: uid at server privilege, live reverse shell, 5 independent chains
  Status: NOT FIXED (CVE-2026-115560 is advisory-only, fix in next routine release)
